# Before submitting MyLittleEnergy

- Confirm the package is free and the description links to the public source.
- Install and test each rootless/RootHide variant on its matching jailbreak.
- Test first launch without a receipt or account, widgets, status-bar displays and HUD.
- Verify cold jailbreak entry, respring, lock/unlock and conflicts with other tweaks.
- Check charging limits, resume, heat pause, full-charge cancellation and restoration after removal. Do not claim the currently unsuccessful XR charging controls work.
- Test alerts, automation, CSV export and accessibility.
- List only verified devices/versions as tested; iOS 16–26 remains the intended range.
- Keep genuine screenshots, a working support contact and a separate changelog.
